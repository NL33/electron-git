There was an error saving a new version of your project.
One possible cause of this error is that you don't have 'Git' installed on your computer.
What's Git?
Git is a tried and true way of saving versions that millions of programmers have used for years.
This app builds on some of that functionality so you can easily save versions of any kind of project. So, to save project versions, compare versions, and more, you'll need Git installed on this computer.
Git comes automatically with Mac computers and Linux computers. If you have a Windows computer, you might not have Git installed yet.
To install Git, please visit https://git-scm.com/downloads and follow the instructions there.
After that, you should be able to get all the power of this app.
