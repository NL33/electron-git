**Integrating Versions and Sharing**

# Goal

make it fluid to save versions locally, and share docs you want to share.

# How it works with Github

With github, I (i) save a version and (ii) push to github.

I used to think of those steps as required for sending to github. In fact, saving a version saves the version to my local system, and then pushing to github is separate.

But it's important for them to be linked.

# Linking version saving and sharing in my app

To link saving a version and sharing in my app, the flow could be:

--save a version when you want to save a version, adding a note.
--then share the files you want to share.

Bottom line: both saving your versions and sharing your work is valuable, just like I do it with git and github.

When you save a version, you enter a note. That note can be helpful for when you share your versions too.

So makes sense process would be:

1. click save version, and enter note.

2. share button appears. and could hit share. And when you do that, files are shared on the site, and each file has the note there (or maybe just the note appears under the project header).

3. On project page, it has a note saying whether it is public or private (so when you share it whether it goes to everyone or just people you've selected; private = "invite only")

4. when you go to send, you select the docs you want to send. 
    --would remember the docs you've selected before, so you don't have to redo each time.
    --maybe option to share all docs.


# Example: Sharing Music

For my logic pro files, I might have:

-logic pro itself
-mp3 file recording of the song draft
-notes on the song
-links to other sites I've used. 

I'd want to save the versions on my own computer. 

Then, hit "send" or "share" to share it.
